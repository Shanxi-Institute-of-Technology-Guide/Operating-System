# Operating System Exercises

C language exercises implementing selected operating-system concepts and simulations.

> Academic context: this directory contains course lab or coursework solutions.

## Topics

- Banker's algorithm for resource-allocation safety
- Processor scheduling

## Compile and Run

```powershell
gcc -std=c17 -Wall -Wextra -o banker Banker_Algorithm.c
.\banker.exe
```

Compile each source file independently.
